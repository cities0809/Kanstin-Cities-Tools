## 重要：資料保存與備份

目前完全使用瀏覽器 `localStorage`，沒有登入、雲端同步、收集玩家資料或後端服務。**不同裝置、瀏覽器、網域（包括本機 HTML 與 GitHub Pages）之間不會自動共享資料。**

新網站使用 `wheat-sword-tools-characters-v1` 來保存多角色；若在**同一網站來源**上找到舊版 `fantasy-pet-planner-v1`，第一次使用時會讀取舊資料作為「角色 1」，不刪除舊版資料。若先前是打開本機 V1.9 HTML，而現在切換到 GitHub Pages，請先從 V1.9 **匯出 JSON**，再到新網站的「匯入目前角色」匯入。

- 「匯出目前角色」：單一角色，`app: fantasy-pet-planner`、`version:1`，支援從舊版 V1.9 匯入。
- 「備份全部角色」：`app: wheat-sword-toolkit`、`version:1`，包含所有角色及目前選取的角色。
- 「匯入目前角色」只會覆蓋目前選取的角色，不影響其他角色。
- 「匯入全部角色」**會取代目前所有角色**，操作前會再次詢問。
- 建議定期備份全部角色；清除瀏覽資料、使用無痕模式或換裝置都可能遺失資料。

## GitHub Pages 上架

**不要只把 ZIP 檔直接上傳成單一檔案！** 請先解壓縮，將下面的檔案放在儲存庫根目錄：

```text
Kanstin-Cities-Tools/
├── index.html       # 首頁與工具集路由
├── styles.css       # 首頁與幻獸工具樣式
├── app.js           # 幻獸計算、多角色及網站互動
├── data.js          # 幻獸數據與材料需求
├── .nojekyll        # 直接提供靜態檔案
├── README.md
└── DEPLOY_GUIDE.md  # 詳細上架步驟、捐款／付費功能注意事項
```

1. 登入 https://github.com ，選擇 **New repository**，例如命名 `Kanstin-Cities-Tools`，建立 **Public** 儲存庫。
2. 將本 ZIP **解壓縮**，使用 GitHub 的 **Add file → Upload files** 上傳 `index.html`、`app.js`、`data.js`、`styles.css` 等原始檔，並 **Commit changes**。
3. 開啟儲存庫的 **Settings → Pages**。
4. 在 **Build and deployment** 選 **Deploy from a branch**，Branch 選 `main`，Folder 選 **/(root)**，然後 **Save**。
5. 部署完成後從 Settings → Pages 的 **Visit site** 開啟。一般專案網址格式：`https://cities0809.github.io/Kanstin-Cities-Tools/`。
6. 測試首頁、角色資料輸入、備份匯出、信件問題回報及手機版。GitHub Pages 只提供靜態網站；需要商業付款、登入及付費權限的功能應使用合適的後端部署。

**路由設計：** 首頁位於 `/#/`（或根路徑），幻獸工具位於 `/#/pet`。使用 `#` 路由可以避免 GitHub Pages 直接重新整理時的 404 問題。所有資源採相對路徑，支援專案子路徑部署。

## 本機使用與測試

- 可直接雙擊 `index.html`，但不同本機 HTML 路徑的瀏覽器儲存機制未必一致，請使用匯出／匯入備份。
